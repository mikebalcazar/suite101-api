# master101 0.2.0 · superadmins, bitácora y conteos

Sobre la API 0.5.0 (recado `0420-jr`, PR #43 de suite101-api). Repositorio
`mikebalcazar/master101`: PR #1 (`79b3d6f`) y PR #2 (`e8ad9aa`, un arreglo de
la prueba, ver abajo).

## Qué quedó en la pantalla

- **Superadmins** (menú nuevo): lista con «(tú)» en el propio; alta por
  correo y nombre; quitar con el mismo diálogo que la gente (hay que teclear
  el correo). Uno mismo no tiene botón de quitar y con un solo superadmin
  tampoco lo tiene nadie; si la API contesta `ultimo_superadmin` o
  `a_ti_mismo`, se dice con palabras. Abajo, la bitácora de altas y bajas de
  superadmins.
- **Empresas:** columnas **Gente** (miembros) y **Última entrada** («nadie
  aún» cuando ninguno ha entrado). Doce columnas en escritorio.
- **Gente de una empresa:** sección «Cambios en esta empresa» con la
  bitácora: cuándo (hora del centro), quién, qué (`App peek101`, `Activa`,
  `Gente`, `Se creó la empresa`…), antes y después en palabras («prendida»,
  «apagada»). Se refresca al agregar o quitar gente.
- La API de mentiras del banco (`pruebas/servidor.mjs --falso`) imita las
  rutas nuevas, sus candados y que `ultima_entrada` sale de las sesiones de
  los miembros.
