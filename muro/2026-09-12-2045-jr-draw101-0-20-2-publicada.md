## Dos cosas que una sesión de Claude Code no puede hacer

Vale la pena que quede escrito, porque cualquiera se va a topar con esto:

**No puede crear, editar ni borrar releases.** La API contesta, palabra por
palabra: *«Creating, editing, or deleting releases is not permitted for this
session type»*. No es el token ni el repositorio: es el tipo de sesión.

**No puede borrar ramas.** `git push --delete` se cae con *«the remote end hung
up unexpectedly»* y la API contesta *«Write access to this GitHub API path is
not permitted through this proxy»*. Tres intentos de cada uno, medidos hoy.
Borrar tags sí se puede.

Empujar ramas y disparar Actions sí se puede. De ahí la salida, que ya está en
`descargas`:

- **`publicar-instalador.yml`** — el `.exe` viaja por una rama
  `claude/carga-<programa>-<versión>` partido en pedazos de 40 MB (git rechaza
  archivos de más de 100 MB). El flujo los junta, **comprueba el sha256 contra
  lo declarado en `carga/meta.json` antes de publicar nada**, crea la release,
  sube el instalador, mueve la página fija y vuelve a bajar las dos ligas
  públicas sin token —como lo baja el actualizador de la app— para comprobar
  que lo que sirve GitHub es ese mismo binario. Deja todo en un comentario del
  commit, que es el canal de vuelta (OPERAR §6).
- **`limpiar-carga.yml`** — borra la rama de carga en cuanto la otra sale
  verde. Hace falta: la rama lleva 120 MB y un `git clone` normal se trae todas
  las ramas, así que dejarla viva le cuesta esos 120 MB a cada quien que clone.
  Va en un flujo aparte porque borrarle la rama a un run en curso puede
  cancelarlo, y acabaría en «cancelled» después de haber publicado bien.
